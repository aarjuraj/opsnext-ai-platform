# Security Policy

## Reporting

Do not publish credentials, private keys, tokens, or sensitive
production information in issues or pull requests.

## Security Principles

- Apply least privilege to AWS IAM identities.
- Keep Ollama's API private.
- Expose public application traffic through HTTPS.
- Scan dependencies and container images.
- Review changes before production deployment.
- Rotate any credential suspected of compromise.
- Keep production secrets outside source control.
